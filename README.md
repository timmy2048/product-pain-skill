# product-pain-skill

从真实痛点出发，筛选或反推评估 D2C 产品的开源 Agent Skill。不绑定某一家模型或插件市场。跑完必须给出结论报告，结论只允许三种：**值得小规模测试**、**淘汰**、**证据不足先停**。

仓库地址：<https://github.com/timmy2048/product-pain-skill>

## 两种用法

- **推荐选品：** 从赛道、人群或痛点出发，找出值得小规模测试的产品方向。
- **反推评估：** 从用户已有的产品、链接或概念出发，用同一套关卡判断该不该做。

两种入口共用关卡、工具和报告模板。

## 快速开始

1. 克隆本仓库，或直接打开 [`SKILL.md`](./SKILL.md)。
2. 让你的 AI 代理读取 `SKILL.md`，并按推荐或反推模式执行。
3. 需要检索链接时，运行 `python scripts/build_search_urls.py --help`。
4. 结论写入 `templates/report.md` 对应的报告；也可用 `python scripts/render_report.py --help` 做必填项校验。

只要代理能加载标准 Agent Skill（根目录有 `SKILL.md`，附件在同层目录），就可以用。常见做法是把本仓库放到项目里，或把 `SKILL.md`、`references/`、`scripts/`、`templates/` 一起复制到该代理的 skills 目录。

## 第一版范围

- 市场：全球英语市场，未指定时默认美、英、澳。
- 必查渠道：Reddit、Amazon、TikTok、YouTube。
- 工具以免费、可公开访问的入口为主：Google 搜索与免费需求量插件、Google Trends（只看涨跌，非必须）、Amazon 公开商品页（重点看 2–3 星评论）、Meta Ad Library、Similarweb 免费版、USPTO 公开商标检索、Google Patents。
- 付费选品套件（如 Helium 10、付费版 Semrush）只作可选增强，不是完整跑完的前提。
- 不提供、也不要求违反网站条款的爬虫。页面打不开或需要登录时，在报告里写明缺口，把该事实标为未核实。

## 关卡

1. 定赛道，挖痛点
2. 确认需求存在，且未见明显衰退
3. 反推产品形态
4. 先筛物流和教育成本（重货、液体、带电或要教市场新习惯的，可能直接出局）
5. 品牌真空判断
6. 对照竞品，写清差异
7. 定位、候选品牌名、宣称边界
8. 合规、知识产权、供应链和单位经济（核不到的数字不要编）
9. 小规模验证（必须放最后；前面没过关不得进入，也不得擅自花费广告预算）

第 4 关通过后，第 5–7 关可以并行；第 8 关在它们之后；第 9 关始终最后。

## 仓库结构

```
SKILL.md                 # 给代理读的英文技能正文
README.md                # 本说明（中文）
LICENSE                  # MIT
templates/report.md      # 结论报告模板
scripts/                 # 生成检索 URL、校验报告（不爬取站点）
references/              # 渠道与工具操作说明
```

## 使用原则

- 不编造搜索量、起订量、出厂价或毛利。
- 商标和品牌名在官方检索完成前，只是候选，不是已清空的名称。
- 不得把未经核实的医疗或功效承诺写成卖点。
- 物流重量和市场教育成本要尽早判断，不要等品牌和开模都做完才发现做不了。
