# product-pain-skill

从真实痛点出发，筛选或反推评估 D2C 产品的开源 Agent Skill。不绑定某一家模型或插件市场。跑完必须给出结论报告，结论只允许三种：**值得小规模测试**、**淘汰**、**证据不足先停**。

仓库地址：<https://github.com/timmy2048/product-pain-skill>

## 两种用法

- **推荐选品：** 从赛道、人群或痛点出发，找出值得小规模测试的产品方向。如果用户只说「帮我找个产品」、没有给出赛道，先走第 0 关：从 Amazon Movers & Shakers、Google Trends 上升词、TikTok Creative Center（打得开的话）和 Reddit 痛点句式里列出 3–5 个候选，按季节、痛点密度和物流风险挑一个，再进入后面的关卡。
- **反推评估：** 从用户已有的产品、链接或概念出发，用同一套关卡判断该不该做。

两种入口共用关卡、工具和报告模板。

## 快速开始

1. 克隆本仓库，或直接打开 [`SKILL.md`](./SKILL.md)。
2. 让你的 AI 代理读取 `SKILL.md`，并按推荐或反推模式执行。
3. 需要检索链接时，运行 `python scripts/build_search_urls.py --help`。推荐模式下若还没有赛道，可加 `--discover`。
4. 结论写入语言对应的报告模板；也可用 `python scripts/render_report.py --help` 做必填项校验。报告按用户要求的语言输出；用户没有指定时默认英语。英文模板是 [`templates/report.md`](./templates/report.md)，中文模板是 [`templates/report.zh.md`](./templates/report.zh.md)。

只要代理能加载标准 Agent Skill（根目录有 `SKILL.md`，附件在同层目录），就可以用。常见做法是把本仓库放到项目里，或把 `SKILL.md`、`references/`、`scripts/`、`templates/` 一起复制到该代理的 skills 目录。

## 第一版范围

- 市场：全球英语市场，未指定时默认美、英、澳。加拿大、爱尔兰、新西兰可按用户要求追加，不是默认必查项。澳大利亚的季节与美、英相反，需求核验时要写明看的是当季还是淡季。
- 必查渠道：Reddit、Amazon、TikTok、YouTube。
- 工具以免费、可公开访问的入口为主：Google 搜索与免费需求量插件、Google Trends（只看涨跌，非必须）、Amazon 公开商品页（能登录时重点看 2–3 星评论，否则用公开的 “Customers say” 摘要）、Meta Ad Library、Similarweb 免费版、USPTO 公开商标检索、Google Patents。
- Reddit Data API 和 Meta Ad Library API 是可选项：用户已经有审核通过的密钥时可以用，没有密钥就走公开页并在报告里记录缺口。不要等审核通过才开始跑关卡。TikTok Research API 只面向获批的学术或非营利研究，不能用于商业选品。Amazon 没有官方的 2–3 星评论文本接口。USPTO 按品牌名检索也没有官方 API，需在浏览器打开商标检索页。
- 付费选品套件（如 Helium 10、付费版 Semrush）只作可选增强，不是完整跑完的前提。
- 不提供、也不要求违反网站条款的爬虫。页面打不开或需要登录时，在报告里写明缺口，把该事实标为未核实。第三方趋势博客和店铺销量快照只是线索，不能当作第 1、2 关的证据。

## 关卡

0. 推荐模式且未给赛道时，先从指定的免费信号里挑选赛道（已给赛道则跳过）
1. 定赛道，挖痛点
2. 确认需求存在，且未见明显衰退（含澳大利亚反季）
3. 反推产品形态（可核对的结构、尺码体系、材料或使用场景才算差异；口号或已有卖点是换皮）
4. 先筛物流和教育成本（重货、液体、带电或要教市场新习惯的，可能直接出局；服装、鞋履、贴身衣物还要看退货和卫生不可退规则）
5. 品牌真空判断
6. 对照竞品，写清差异（只有口号，或声称的差异已出现在竞品页上，则本关失败）
7. 定位、候选品牌名、宣称边界；审美参照要跨界移植目标人群喜欢的其他品类大牌，不要抄同行老牌。本关用「已完成 / 未完成」，不用通过/失败
8. 合规、知识产权、供应链和单位经济（核不到的数字不要编）
9. 小规模验证（必须放最后；前面没过关不得进入，也不得擅自花费广告预算）。产品可测后，先用自然流量短视频试痛点钩子；一旦出现高完播视频，广告预算优先投给看完约 95% 的人，再转化第一批种子用户

第 4 关通过后，第 5–7 关可以并行；其中一关未通过或未核实时，先写完已经开始的 5–7 关，再停在第 8 关之前。第 8 关在它们之后；第 9 关始终最后。某一关失败后仍要出完整报告，未评估的部分写「未评估——停在第 N 关」。

各关状态只允许：通过、未通过、未核实（第 7 关为已完成/未完成）。未通过通常对应「淘汰」；必须项未核实对应「证据不足先停」；第 1–8 关都通过且第 7 关已完成，才是「值得小规模测试」（不必已经进入第 9 关）。


## 使用原则

- 不编造搜索量、起订量、出厂价或毛利。
- 商标和品牌名在官方检索完成前，只是候选，不是已清空的名称。
- 不得把未经核实的医疗或功效承诺写成卖点。
- 物流重量、退货卫生规则和市场教育成本要尽早判断，不要等品牌和开模都做完才发现做不了。
- 用作证据的价格必须写明看到的日期和站点，不要把媒体报道里的价格当成在售价。
